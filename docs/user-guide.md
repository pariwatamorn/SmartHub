# คู่มือผู้ใช้งาน — สำหรับผู้รับผิดชอบ

## เริ่มใช้งาน
1. เปิดไฟล์ `app/index.html` ด้วยเบราว์เซอร์ (ไม่ต้องติดตั้งโปรแกรมเพิ่ม)
2. กรอก "ผู้ใช้งาน" เป็นตำแหน่ง/หน่วยงาน และ "ปีแผน ACP"
3. ฝึกใช้งาน: แท็บ 3 → "โหลดข้อมูลตัวอย่าง" (ข้อมูลสมมติ)

## ถ้าคุณเป็น Risk Owner (1st line)
- แท็บ **3. ประเมินความเสี่ยง** → เพิ่มหรือแก้ไขความเสี่ยงของหน่วยงาน
- เลือก Likelihood ตามคำอธิบายที่แสดงใต้ช่อง และให้คะแนน Impact ทั้ง 4 มิติ
- ประเมินการควบคุมทั้ง Design และ Operating โดยอ้างผล testing/audit
- **ต้องเขียนเหตุผลทุกช่อง** — ระบบจะแสดงที่มาของผลคำนวณทันทีด้านล่างฟอร์ม
- หาก Residual เป็น "สูง/สูงมาก" ต้องกรอกแผนแก้ไข ผู้รับผิดชอบ และกำหนดเสร็จ

## ถ้าคุณเป็น Compliance / DBR (2nd line)
1. แท็บ **2** — ตรวจว่า regulator ทุกรายมีความเสี่ยง หรือบันทึกเหตุผลว่าไม่เกี่ยวข้อง
2. แท็บ **3/4** — สอบทานคะแนนและดู heat map; แก้ไขเมื่อเห็นต่าง (ระบบบันทึก audit trail)
3. แท็บ **5** — "สร้างร่าง ACP" แล้วปรับผู้รับผิดชอบ/ช่วงเวลา
4. แท็บ **6** — แก้ไขจนไม่มี FAIL (ยกเว้น BB-07 การอนุมัติ และ BB-11 ที่ติดตามระหว่างปี)
5. แท็บ **5** — "ส่งทบทวน/เสนออนุมัติ" และ Export CSV แนบวาระการประชุม

## ถ้าคุณเป็น Head of Compliance / เลขานุการคณะกรรมการ
- หลังที่ประชุมมีมติ ให้กด "บันทึกผลการอนุมัติ" ระบุผู้อนุมัติ บทบาท วันที่ เลขที่มติ หรือส่งกลับแก้ไข
- ระหว่างปีให้ปรับสถานะกิจกรรม และใช้แท็บ 6 ดูรายการเกินกำหนดเพื่อ escalate

## คำถามที่พบบ่อย
- **ระบบอนุมัติแทนได้ไหม?** ไม่ได้ ระบบเป็นเครื่องมือช่วยตัดสินใจ การอนุมัติต้องทำโดยผู้มีอำนาจเท่านั้น
- **ไม่ทราบเลขที่ประกาศ?** ให้ระบุชื่อเรื่องและเขียน "(ต้องตรวจสอบ)" ห้ามเดาเลขที่
- **ข้อมูลหายเมื่อเปลี่ยนเครื่อง?** ข้อมูลอยู่ในเบราว์เซอร์ ให้ Export/Import JSON ที่แท็บ 7
