# Compliance Risk Assessment & Annual Compliance Program (DRAFT v0.1)

ร่างระบบประเมินความเสี่ยงด้าน compliance (CRA) และการกำกับ Annual Compliance Program สำหรับ SmartHub

| ไฟล์ | เนื้อหา |
| --- | --- |
| `KTB_Compliance_Risk_Assessment_Annual_Program.xlsx` | Parameters, Obligation Register, CRA (สูตร Inherent/Residual/ความถี่), Annual Plan, Issue Tracker (SLA), KRI (RAG), Blue Book Mapping, Approval Log |
| `cra-prototype.html` | Prototype หน้าเว็บ: ให้คะแนน CRA, residual heatmap 5x5, แผนทดสอบรายไตรมาส |

เอกสารออกแบบฉบับเต็มอยู่ใน Claude Docs (ลิงก์ใน PR)

**สถานะ:** ยังไม่ map กับ Blue Book (คู่มือภายใน KTB) — คอลัมน์ Blue Book ref ทั้งหมดเป็น "ต้องตรวจสอบ"
ค่าคะแนน เกณฑ์ SLA และความถี่ทดสอบเป็นค่าเสนอเบื้องต้น ข้อมูลในแถวตัวอย่างไม่ใช่ข้อมูลจริง

> ข้อมูลนี้เป็นการสนับสนุนการพิจารณาเบื้องต้น มิใช่ความเห็นทางกฎหมายที่สิ้นสุด โปรดสอบทานโดยผู้รับผิดชอบและตรวจสอบกับฉบับกฎเกณฑ์ล่าสุดก่อนนำไปใช้
